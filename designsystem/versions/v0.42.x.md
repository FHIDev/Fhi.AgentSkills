# Delta: v0.42.x

## Scope

Gjelder v0.42.x (0.42.0–0.42.2).
Skrevet mot: v0.43.5. Innhold er kumulativt — gyldige avvik vs. enhver nyere latest.
Seksjoner uten avvik er utelatt — se «Verifisert uendret vs latest».

Features innført i v0.41+ slås opp i [FEATURES.md](FEATURES.md), blant annet
`fhi-link` og de nye Select-atferdene. De listes ikke som «Missing» her.

## Different vs latest

### Select

- En initial `value` på `fhi-select` kan overskrives av første alternativ.
  Bruk `selected` på ønsket `fhi-select-item` for forhåndsvalg i v0.42.x.
- Barnas `selected`-, `value`- og `label`-attributter observeres ikke. En slik
  endring alene rendrer ikke alternativlisten på nytt.
- Fallback-verdi fra tekstinnhold beholder innledende og etterfølgende
  mellomrom. Latest trimmer disse.
- Etter programmatisk endring av select-feltets egen `value` kan visning og
  FormData avvike. Denne begrensningen finnes også i latest; oppgradering alene
  løser den ikke. Se [Select](../references/components/fhi-select.md).

## Patch notes med API-impact

- **v0.42.1:** `show()` etterfulgt av `close()` på modal-dialogen gjenoppretter
  sidens scrolling. I v0.42.0 kan `body.style.overflow` bli stående som `hidden`.
- **v0.42.2:** modalbredde kan overstyres via `--fhi-modal-dialog-width` på
  vertselementet. I v0.42.0–v0.42.1 har den nye variabelen ingen effekt.
  Gamle `--dimension-dialog-width-small/medium` og øvrige
  `--dimension-dialog-*` fjernes i v0.42.2, så overstyringer av dem slutter å virke.
  Dette er endring i faktisk CSS-atferd; de gamle variablene var ikke et
  dokumentert stabilt API.

## Verifisert uendret vs latest

- Eksisterende komponenters attributter, events og metodesignaturer: uendret
  i manifest-diff v0.42.2 → v0.43.5; runtime-avvikene er beskrevet over.
- Eksisterende exports, alle 104 ikon-entrypoints, theme- og fontstier: uendret.
- Tokens/theme: alle 300 globale token-navn og verdier er identiske.
- Avhengighetskrav: uendret, inkludert peerDependency `lit ~3.2.0`.
- React/Angular/Blazor-oppsett: ingen nye oppsettkrav i latest.
- Checkbox-reset og radio-reset uten forhåndsvalg: samme begrensninger som
  latest, se [Form-bruk](../references/form-usage.md).

## Migrering (0.42 → 0.43.5)

- For dynamiske Select-alternativer: se skillet mellom observerte
  barneattributter og feltets egen `value` i komponentreferansen.
- Bruk eksplisitt alternativverdi dersom mellomrom i verdien er tilsiktet.
- Fra v0.42.0–v0.42.1: flytt eventuell egendefinert modalbredde til
  `--fhi-modal-dialog-width`. Andre fjernede CSS-overstyringer har ikke
  nødvendigvis en direkte erstatning. Den nye variabelen har heller ingen
  dokumentert stabilitetsgaranti.

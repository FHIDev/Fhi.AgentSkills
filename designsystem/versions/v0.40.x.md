# Delta: v0.40.x

## Scope

Gjelder v0.40.x (alle patcher, 0.40.0–0.40.7).
Skrevet mot: v0.41.2. Innhold er kumulativt — gyldige avvik vs. enhver nyere latest.
Seksjoner uten avvik er utelatt — se «Verifisert uendret vs latest».

Features innført i v0.41+ (bl.a. `fhi-select`/`fhi-select-item`) slås opp i
[FEATURES.md](FEATURES.md) — de listes ikke her (dekningsgrense v0.41.0).

## Verifisert uendret vs latest

- Missing/Different/Legacy-only (før dekningsgrensen): ingen avvik
- Komponenter: public API identisk med latest (manifest-diff v0.40.0 vs v0.41.2 viser
  kun nye Select-komponenter og typografi-endringen i 0.40.7, se patch notes)
- Tokens/theme: alle token-verdier i `theme/default.css` identiske med v0.41.2
  (kun formatering og font-referanse er endret, se patch notes for 0.40.2)
- peerDependencies: uendret (`lit ~3.2.0`)
- Rammeverk (React/Angular/Blazor): ingen avvik utover font-notatet for 0.40.0–0.40.1

## Patch notes med API-impact

- **v0.40.2:** `theme/default.css` refererer nå fonten som egen fil
  (`fonts/RobotoFlex.ttf`, ny i pakken) i stedet for innbakt base64 — filen krympet fra
  ~2,3 MB til ~15 kB. I v0.40.0–v0.40.1 er fonten innbakt, og pakken har ingen egen
  `fonts/RobotoFlex.ttf`-fontfil som må kopieres (`fonts/` inneholder kun et
  `RobotoFlex.ttf.js.map`-artefakt); Blazor-notatet om å kopiere `fonts/` gjelder
  derfor ikke der.
- **v0.40.6:** styling-fix for `fhi-radio` med `disabled` + `status="error"` samtidig.
- **v0.40.7:** typografikomponentene sluttet å sette `color` som inline-style når
  attributtet ikke er satt (property-default gikk fra strengen `'currentcolor'` til
  `undefined`). Visuell default er fortsatt arv fra forelder, men i v0.40.0–v0.40.6
  fungerer ikke ekstern CSS (f.eks. `fhi-body { color: … }`) som fallback.
- v0.40.3–v0.40.5 refaktorerte komponent-interne tokens (button, checkbox, radio) —
  shadow-DOM-interne, ingen public API-endring.

## Migrering (0.40 → 0.41.2)

- Bakoverkompatibel oppgradering. Ingen kodeendringer nødvendige.
- Nye komponenter `fhi-select`/`fhi-select-item` blir tilgjengelige (se FEATURES.md).
- Fra v0.40.0/v0.40.1: merk at fonten nå er egen fil — kopier `fonts/`-mappen i
  oppsett som kopierer pakkefiler manuelt (f.eks. Blazor).

# Delta: v0.39.x

## Scope

Gjelder v0.39.x (alle patcher).
Skrevet mot: v0.40.0. Innhold er kumulativt — gyldige avvik vs. enhver nyere latest.
Seksjoner uten avvik er utelatt — se «Verifisert uendret vs latest».

## Missing vs latest

### fhi-tag

- Mangler `variant="bordered"`. Variant-attributtet ble innført i v0.40.0
  (`'subtle' | 'bordered'`, default `'subtle'`). I v0.39.x finnes kun subtle-stilen.

## Verifisert uendret vs latest

- Different/Legacy-only: ingen avvik

## Migrering (0.39 → 0.40)

- Bruk `variant="bordered"` på `fhi-tag` hvis du vil ha kantlinje etter oppgradering.

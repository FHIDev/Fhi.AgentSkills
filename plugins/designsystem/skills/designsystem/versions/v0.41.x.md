# Delta: v0.41.x

## Scope

Gjelder v0.41.x (0.41.0–0.41.3).
Skrevet mot: v0.43.5. Innhold er kumulativt — gyldige avvik vs. enhver nyere latest.
Seksjoner uten avvik er utelatt — se «Verifisert uendret vs latest».

Features innført i v0.41+ slås opp i [FEATURES.md](FEATURES.md), blant annet
`fhi-callout`, `fhi-link`, modalbredde og nye Select-atferder.
De listes ikke som «Missing» her.

## Different vs latest

### Select

- En initial `value` på `fhi-select` kan overskrives av første alternativ.
  Bruk `selected` på ønsket `fhi-select-item` for forhåndsvalg i v0.41.x.
- Barnas `selected`-, `value`- og `label`-attributter observeres ikke.
  Endringer i dem alene rendrer ikke alternativlisten på nytt.
- Fallback-verdi fra tekstinnhold beholder innledende og etterfølgende
  mellomrom. Latest trimmer disse.
- Programmatisk endring av select-feltets egen `value` kan gi ulik verdi i
  visningen og FormData. Begrensningen består i latest; se
  [Select](../references/components/fhi-select.md).

### Modal-dialog

`show()` etterfulgt av `close()` kan etterlate `body.style.overflow='hidden'`,
slik at siden ikke kan scrolles. Dette er rettet fra v0.42.1.

## Legacy-only

Modalens `--dimension-dialog-width-small/medium` og øvrige
`--dimension-dialog-*` kan overstyres på vertselementet i v0.41.x. Disse
fjernes i v0.42.2. Overstyringer slutter dermed å ha effekt etter oppgradering.
Variablene var ikke et dokumentert stabilt API.

## Patch notes med API-impact

- **v0.41.1–v0.41.2:** interne token-refaktoreringer i grid/flex.
  De dokumenterte attributtene og globale theme-tokenene er uendret.
- **v0.41.3:** tooltipens CSS bruker globale tokens direkte og fjerner
  tidligere variabler på vertselementet, blant annet `--color-background`
  og `--dimension-padding`. Apper som overstyrte disse udokumenterte
  variablene mister tilpasningen. Komponentmanifestet og globale
  `theme/default.css` er identiske med v0.41.2. Den publiserte tooltip-bundelen
  inneholder også endret Floating UI-kode; patchen er ikke bare en
  avhengighetsversjonsendring.

## Verifisert uendret vs latest

- Eksisterende komponenters attributter, events og metodesignaturer: uendret
  i manifest-diff v0.41.2/v0.41.3 → v0.43.5; runtime-avvikene er beskrevet over.
- Eksisterende exports, alle 104 ikon-entrypoints, theme- og fontstier: uendret.
- Tokens/theme: alle 300 globale token-navn og verdier er identiske.
- Avhengighetskrav: uendret, inkludert peerDependency `lit ~3.2.0`.
- React/Angular/Blazor-oppsett: ingen nye oppsettkrav i latest.
- Checkbox-reset og radio-reset uten forhåndsvalg: samme begrensninger som
  latest, se [Form-bruk](../references/form-usage.md).

## Migrering (0.41 → 0.43.5)

- Bruk eksplisitt alternativverdi dersom mellomrom i Select-verdien er tilsiktet.
  Se komponentreferansen før du bruker dynamiske alternativendringer.
- Flytt eventuell egendefinert modalbredde til `--fhi-modal-dialog-width`.
  Andre gamle modal-/tooltip-overstyringer har ikke nødvendigvis en direkte
  erstatning. Den nye breddevariabelen er verifisert CSS-atferd uten
  dokumentert stabilitetsgaranti.

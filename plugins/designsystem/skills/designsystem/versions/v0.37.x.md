# Delta: v0.37.x

## Scope

Gjelder v0.37.x (alle patcher).
Skrevet mot: v0.40.0. Innhold er kumulativt — gyldige avvik vs. enhver nyere latest.
Seksjoner uten avvik er utelatt — se «Verifisert uendret vs latest».

## Missing vs latest

### fhi-tag

- Mangler `variant="bordered"` (innført i v0.40.0).

### Ikoner

- Mangler `fhi-icon-file-text` (innført i v0.38.0). `fhi-icon-file` finnes.

## Different vs latest

### Typografikomponenter (fhi-body, fhi-display, fhi-headline, fhi-label, fhi-title)

- Default `color` er `var(--fhi-color-neutral-text-default)`, **ikke** `currentcolor`
  (currentcolor innført i v0.39.0).

## Verifisert uendret vs latest

- Legacy-only: ingen
- Import/entrypoints: uendret — Data Table (`fhi-data-table`, `fhi-data-table-row`,
  `fhi-data-table-cell`) finnes (innført i v0.37.0)
- Theme/tokens: `theme/default.css` byte-identisk med v0.40.0
- Rammeverk (Blazor): ingen avvik
- Patcher: ingen kjente med API-impact (kun v0.37.0 publisert i 0.37-serien)

## Migrering (0.37 → 0.40)

- Bakoverkompatibel oppgradering.
- `fhi-icon-file-text` blir tilgjengelig fra v0.38.0.
- Typografikomponenter arver farge (`currentcolor`) fra v0.39.0.
- `fhi-tag variant="bordered"` blir tilgjengelig fra v0.40.0.
